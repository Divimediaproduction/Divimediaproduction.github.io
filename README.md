# Divyanshi Srivastava – 2D Animator & Illustrator

Portfolio website, hosted with GitHub Pages.

- `index.html` – the full site (HTML and CSS in one file)
- `assets/` – portrait and Instagram QR code

## Publish on GitHub Pages
1. Create a new repository on GitHub (for example `portfolio`).
2. Upload everything in this folder to the repository root.
3. Go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
